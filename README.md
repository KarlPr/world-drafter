# World Drafter

Map-authoring tool for Clausewitz/Jomini custom-map mods. Design: [docs/clausewitz-map-editor-design.md](docs/clausewitz-map-editor-design.md).

```
npm install
npm run dev     # editor at http://localhost:5173
npm test        # node --test over src/**/*.test.ts
npm run build   # tsc + vite
```
